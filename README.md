# Forklore 🍴

App mobile React Native che permette di esplorare i piatti tipici delle 20 regioni italiane, con descrizione, storia e immagine recuperate dall'API di Wikipedia in italiano.

## Funzionalità

- Sfoglia le regioni d'Italia
- Scopri i piatti tipici di ciascuna regione
- Leggi descrizione, storia e curiosità di ogni piatto (da Wikipedia)
- Salva i tuoi piatti preferiti (disponibili anche offline)

## Stack tecnico

- **React Native** + TypeScript
- **React Navigation** — navigazione tra schermate (tab bar + stack)
- **TanStack Query** — gestione delle chiamate all'API di Wikipedia
- **React Native MMKV** — persistenza locale dei preferiti
- **FlashList** — liste performanti
- **Wikipedia REST API** (it.wikipedia.org) — fonte dei contenuti
